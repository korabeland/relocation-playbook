# Quick capture

Use when the user says something like "add to backlog: ...", or mentions something worth keeping while working on something else.

Approval contract: see `AGENTS.md`. Appending to `BACKLOG.md` is allowed without asking. Creating a task on the board is a board write and needs a yes first.

1. Decide whether the item is clear and actionable, or vague.
2. If it is vague or needs thinking, append a line to `BACKLOG.md` in the form `- YYYY-MM-DD: item`, and say you did.
3. If it is clear and actionable, draft the task for the board: title, Phase, Owner, Category, Due if known. Show the draft and wait for a yes before creating it. If the user declines or does not answer, append it to `BACKLOG.md` instead.
4. Check `BACKLOG.md` and `state/board-snapshot.md` for an existing entry first. If a similar one exists, say so rather than adding a duplicate.

Capturing a thought is not the same as committing to it. Nothing captured here changes `state/` until session close.

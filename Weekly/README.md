# Weekly

Short records of sessions and weekly summaries.

- `Weekly/YYYY-MM-DD.md`: a weekly summary, from `templates/weekly-summary.md` and `workflows/weekly-summary.md`.
- `Weekly/YYYY-MM-DD-session.md`: a daily session log, written at session close when state changed. Append each session under its own numbered heading, labeled solo or shared, preserving earlier sections. Each session has four parts: topics discussed, decisions made, tasks updated, next steps.

Keep them brief and scannable. They are a reference log and not a complete archive of conversations. Gaps in dates are normal: some sessions change nothing and need no record.

A session record points at the records in `state/` for detail rather than repeating them. This folder stays owner-only; share only reviewed, approved copies in the separate household output location.
